# Sign Language Classifier

This project trains a deep learning model to recognize Sign Language (A-Z) using hand landmarks extracted from webcam images.

## 📂 Project Structure
- `src/` — All source code for collecting data, training, and testing
- `models/` — Pretrained model and label encoder
- `data/` — Folder where the images we collected images are stored. It can also be used to store the images collected by running the collect_images.py script.
- `requirements.txt` — Python dependencies
